## Security policy

This project must remain fail-closed around credentials and operational claims.

Do **not** commit:

- `.env`
- `.env.local`
- Supabase service role key
- wallet/private keys
- Zenodo keys
- GitHub tokens
- connector credentials
- seed phrases

Frontend-safe variables only:

```bash
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
# or:
VITE_SUPABASE_PUBLISHABLE_KEY=
```
